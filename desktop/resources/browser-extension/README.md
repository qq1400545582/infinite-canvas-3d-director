# 一键发送图片 / 视频到无限画布

把看到的图片、视频，以及**本机硬盘里的图片 / 视频**，一键变成画布上的一个节点。三类环境各有对应通路：

| 你在哪 | 用哪条通路 | 要装东西吗 |
|---|---|---|
| Edge / Chrome / 360 等常规浏览器（看网页上的图） | 扩展：右键菜单 / 悬停按钮 / 弹窗批量 | 装扩展（v1.2.0） |
| 常规浏览器（发**本机文件**） | 扩展：弹窗「选择本机文件」/ `Alt`+拖入 / `Alt`+`V` 粘贴截图 | 装扩展（v1.2.0） |
| **任意工具的内置浏览器**（装不了扩展） | **网页版发送台**：`http://127.0.0.1:3000/send` | 不用装，Token 自动获取 |
| 装不了扩展的老浏览器（IE 内核 360 等） | 书签小工具：点书签拾取网页里的图 | 拖一个书签 |

四条通路共用同一条发送链路，**没有改动画布前端与 Canvas Agent 的一行业务代码**（见末尾「实现原理」）。

---

## 一、前置条件（两条都要满足）

1. 浏览器里**打开着画布页面**；
2. 画布的智能体**已连接本机 Canvas Agent**（画布里的「一键启动 Canvas Agent」，或桌面端已自动启动）。

节点是 Agent 推给「当前已连接的画布页面」创建的，两者缺一不可。不满足时会收到明确提示（「请先打开一个画布页面并保持连接，再发送」）。

> 发送台页面（`/send`）会自己显示这两条前提的状态，不用手动判断。

## 二、取 Token

在本机执行：

```bash
node browser-extension/show-agent-token.cjs
```

会打印 Canvas Agent 地址（默认 `http://127.0.0.1:17371`）与 Token。也可以自己打开
`C:\Users\<你>\.infinite-canvas\canvas-agent.json` 复制 `token` 字段。

## 三、安装扩展

1. 浏览器打开扩展管理页，打开「开发者模式」：
   - **Chrome**：`chrome://extensions`
   - **Edge**：`edge://extensions`
   - **360 安全浏览器**（Chromium 新版）：`se://extensions` 或「扩展管理」页；若找不到入口，用菜单 → 扩展 → 管理
2. 点「**加载已解压的扩展程序**」，选择本目录 `browser-extension/`；
3. 点扩展的「详细信息 → 扩展选项」，填入 Token 与 Agent 地址，点「保存」，再点「测试连接」确认提示「已连通」。

> - 360 安全浏览器老版本（IE 内核）无法安装 Chromium 扩展，请用下面的书签小工具。
> - 从 1.1.0 起，扩展需要「**读取和更改您在所有网站上的数据**」权限：更新/重载扩展后浏览器会弹权限确认，**点允许**，否则无法抓取图片内容转存（见「实现原理」）。重载入口：扩展管理页找到本扩展点「重新加载」。

## 四、使用

> **图片和视频都会尽量「转存内嵌」再发**（v1.3.0 起视频也内嵌）：画布是本机页面，外链媒体常被防盗链 / 签名过期 / 需要 Referer 拒绝——图片会空白、视频会黑屏。抓到内嵌后，画布里可直接显示 / 播放。
> 体积上限：图片 5MB、视频 8MB；超限或抓不到时按外链直发，提示条会写明原因（如「图源拒绝访问 HTTP 403」），可据此判断是该换源还是压缩后再发。

### 网页上的图片 / 视频

| 方式 | 操作 |
|---|---|
| 右键菜单 | 在图片上右键 →「发送这张图片到无限画布」；视频同理；指向图片/视频文件的链接也支持 |
| 悬停按钮 | 鼠标停在图片或视频上，右上角浮出「发送到画布」，点一下即发（可在设置里关闭） |
| 批量发送 | 点扩展图标 → 列出本页最多 40 个图片/视频 → 勾选 →「发送选中」 |
| 书签小工具 | 点书签进入拾取模式 → 高亮后点击即发，可连续发，`Esc` 退出 |

### 本机文件（v1.2.0 新增）

| 方式 | 操作 |
|---|---|
| 弹窗选择 | 点扩展图标 → 顶部「本机图片 / 视频」区 →「选择本机文件」（可多选），或直接把文件拖进那个区域 |
| `Alt` + 拖拽 | 在任意网页按住 `Alt` 把本机文件拖进页面，松手即发（**不带 Alt 时完全不动网页原生拖拽上传**） |
| `Alt` + `V` | 截图后按 `Alt`+`V` 粘贴即发（网页自己的 `Ctrl`+`V` 粘贴保持原样） |

体积上限：图片 5MB、视频 8MB（内嵌进 dataURL 的膨胀已算好）；超限的文件会被跳过并在提示里说明原因，一次最多 20 个。本机视频同样按 dataURL 内嵌，画布里可直接播放。

### 装不了扩展的内置浏览器：用发送台

本机打开 **`http://127.0.0.1:3000/send`**（桌面端在跑时是它；若是网页版部署，请让管理员在本机跑一次桌面端或 `canvas-agent` 服务）：

- 拖入本机图片/视频、点按钮选择、`Ctrl`+`V` 粘贴截图、粘贴图片直链，四种入口；
- **Token 自动获取**：页面与本机服务同源，会自动从 `/__canvas-agent/status` 读出连接 Token，无需手工粘贴；
- 顶部两个徽标实时显示「Agent 是否连上」「有没有画布页面连着」，不满足条件会直接告诉你。

发送成功会有提示；失败会直接说明原因（未连接 / Token 无效 / 画布未打开 / 文件超限）。

## 五、书签小工具（装不了扩展的浏览器）

**先说清它是什么**：书签小工具**不是安装进浏览器的插件**（那是上面的扩展），而是**一个书签**——把一段 `javascript:` 拖到书签栏**一次**，之后在任意网页点一下它，就进入拾取模式（鼠标移到图片上高亮，点击即发，可连发，`Esc` 退出）。

### 方式 A：网页版一键生成（推荐，小白用这个）

本机打开 **`http://127.0.0.1:3000/send`**，拉到页面下方「书签小工具」卡片：

1. 点「**发送到画布（拖我到书签栏）**」并拖到书签栏（书签栏没显示就按 `Ctrl`+`Shift`+`B`）；
2. 打开任意有图/视频的网页，点一下这个书签 → 进入拾取模式 → 点图即发；
3. 不想拖拽就点「复制书签代码」，手动新建书签把代码填进「网址」。

Token 由页面**自动获取并内嵌**（与发送台同一套发现机制），**不用开终端、不用手工复制 Token**。卡片上也有「在本页立即试一下」按钮，先试一次再装。

> 书签里内嵌了本机连接 Token：浏览器若开启书签同步会把它上传到你的浏览器账号，**不要把这个书签分享或导出给别人**。

> **装书签必须在真正的浏览器窗口里做**：各类桌面工具、IDE、聊天客户端的**内置浏览器 / webview / iframe 里没有书签栏可拖**，页面会自动检测并提示你在 Chrome / Edge 里打开本页再装。这种环境下请直接用发送台（拖拽 / 粘贴 / 选文件）发图，功能不受影响。

### 方式 B：本地脚本生成（离线 / 想留档）

```bash
node browser-extension/make-bookmarklet.cjs
```

会生成 `browser-extension/bookmarklet.html`，打开它把按钮拖到书签栏即可（Token 已内嵌，**别外传这份文件**）。两种方式生成的脚本逐字节一致（有单测守护：`node .workbuddy/tmp/test-bookmarklet.mjs`）。

**已知限制**：知乎、GitHub 等 CSP 严格的站点会拦截书签脚本执行——这是浏览器对 `javascript:` 书签的安全限制，不是本工具的问题；这类站点请改用扩展（扩展的内容脚本不受页面 CSP 限制）。

## 六、分发包（换浏览器 / 发给别人）

扩展是纯静态文件，换浏览器或给别人用，三种取法任选：

| 渠道 | 位置 | 适用 |
|---|---|---|
| 本机应用直下 | 桌面端运行时打开 `http://127.0.0.1:3000/downloads/send-to-infinite-canvas.zip` | 最方便，桌面应用开着就能下 |
| 桌面安装目录 | `%LOCALAPPDATA%\Programs\infinite-canvas-desktop\resources\browser-extension\`（下次打包起随安装包携带） | 装了桌面端的人：免下载，直接「加载已解压的扩展程序」选这个文件夹 |
| 直接转发 | 仓库内 `browser-extension/releases/send-to-infinite-canvas.zip`（约 26KB） | 微信 / 邮件把 zip 发给对方 |

**安装**：解压 zip → 浏览器扩展管理页开「开发者模式」→「加载已解压的扩展程序」选解压出的 `send-to-infinite-canvas` 文件夹 → 扩展选项里填 Token。**Token 要在对方自己的电脑上取**：运行 `node show-agent-token.cjs`（zip 内自带），或打开 `%USERPROFILE%\.infinite-canvas\canvas-agent.json` 复制 `token` 字段。

> - zip 是**稳定名**，每次执行 `node browser-extension/make-extension-zip.cjs` 会整体重新生成并同步到上表所有位置（版本看包内 `manifest.json`）。
> - **分发包不含 `bookmarklet.html`**：书签生成时会内嵌本机 token，属个人凭据，不能外传。对方需要书签就自己跑 zip 内的 `node make-bookmarklet.cjs`。
> - 下载位 `web/public/downloads/` 会随后续构建进入部署产物：站点（如 Wasmer / CF Pages）下次部署后，`https://<站点域名>/downloads/send-to-infinite-canvas.zip` 即公网下载地址。

## 七、实现原理（为什么不用改现有代码）

```
浏览器（扩展 / 书签）
   │  拿到媒体直链 + Token
   │  【仅扩展·图片】先抓取图片本体 → 转 dataURL 内嵌
   │    （扩展后台有 <all_urls> 权限：fetch 免 CORS、不带页面 Referer，
   │      可绕过大多数防盗链；>5MB / 403 / 失败时自动降级为外链直发）
   ▼
本机 Canvas Agent  POST /api/tools  { name: "canvas_create_node",
                                      input: { nodeType: "image"|"video",
                                               metadata: { content: "<dataURL 或 直链>",
                                                           remoteUrl?: "<原始直链>", status: "success", … } } }
   │  Agent 的 CORS 逻辑会把「带有效 Token 的新来源」自动加入白名单，故任意站点来源都能跨域调用
   ▼
已连接的画布页面 执行 add_node → 画布出现图片 / 视频节点
```

- 画布的图片 / 视频节点本身就以 `metadata.content` 作为 `src`（`<video src={content}>`、图片同理）。视频体积大，保持原始直链；图片若仍发外链，遇到防盗链 / 签名 URL 时画布页面（`127.0.0.1` 来源）加载会被拒（403），节点建成但**内容空白**——这正是 1.1.0 修复的问题：扩展发送前把图抓下来转成 dataURL 内嵌进节点，原始直链写在 `metadata.remoteUrl` 留档。
- 页面内部的 `blob:` 图片（canvas 截图、懒加载占位等）只有原页面能读到：悬浮按钮 / 批量发送会在页面里就地转成 dataURL 再交给后台；右键菜单路径拿不到 blob 内容，会明确报错提示。
- 书签小工具运行在页面上下文，受 CORS 限制无法抓取跨域图片，**仍然发原始直链**（遇到防盗链可能空白）；这是书签形态的固有限制，优先用扩展。
- 因此本目录是**纯新增**：不含对 `web/`、`canvas-agent/src/`、`desktop/` 的任何修改，也不会影响其它板块。

## 八、常见问题

| 现象 | 原因与处理 |
|---|---|
| 「连不上本机 Canvas Agent」 | Agent 没启动。在画布里点「一键启动 Canvas Agent」，或确认端口是 17371（改过端口就在设置里改地址） |
| 「Token 无效」 | Token 变了（Agent 重启会重新生成）。重新跑 `show-agent-token.cjs` 再填 |
| 「请先打开一个画布页面并保持连接」 | 当前没有画布页面与 Agent 保持连接，打开画布页面即可 |
| 视频发送后不能播放 | 该站用的是 HLS/DASH，地址是页面内部的 `blob:`，无法跨上下文使用。工具会直接拦截并提示；请用视频的原始直链 |
| 图片节点显示空白（扩展） | 1.1.0 起扩展会自动把图转存为 dataURL 内嵌，正常不再空白。发送成功的提示会注明模式：**「原图已内嵌 v1.1.1」**= 已转存；**「未能内嵌原图：原因…」**= 降级外链（图片超 5MB / 图源拒绝访问 / 网络抓取失败等），画布可能空白。若提示里**完全没有 v 字样**，说明浏览器还在跑旧版扩展——到扩展管理页点「重新加载」并允许新权限 |
| 图片节点显示空白（书签） | 书签运行在页面上下文、无法抓取跨域图片，只能发原始直链，遇到防盗链/被拦截就会空白。请改用扩展（会自动转存） |
| 重载扩展后提示需要新权限 | 1.1.0 起 host_permissions 放宽到所有网站，用于抓取图片本体转存。在弹窗里点允许即可；不授权则图片退回外链直发（可能空白），视频发送不受影响 |
| 悬浮按钮不出现 | 设置里被关掉了，或在 `chrome://` 等受限页面（受限页面不注入脚本，属正常） |
