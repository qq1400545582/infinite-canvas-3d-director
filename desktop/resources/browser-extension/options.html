发送到无限画布

把网页上的图片、视频一键发送到本机无限画布，作为画布节点。

本机图片也能发：三条路任选——① 点扩展图标，在「本机图片 / 视频」区选择或拖入文件；② 在任意网页 Alt + 拖入本机文件；③ 截图后按 Alt + V 粘贴。

装不了扩展的内置浏览器？用网页版发送台：本机打开 http://127.0.0.1:3000/send（桌面端或本机服务在跑时可用），拖入 / 粘贴 / 填链接都能发，Token 自动获取。

Token 在哪拿？在本机执行下面任一方式：

· 运行 node browser-extension/show-agent-token.cjs（仓库自带，直接打印地址与 Token）；

· 或打开 C:\Users\<你>\.infinite-canvas\canvas-agent.json，复制 token 字段。

用之前要满足两个前提：① 浏览器里打开着画布页面；② 画布的智能体已连接本机 Canvas Agent（可点画布里的「一键启动 Canvas Agent」）。
